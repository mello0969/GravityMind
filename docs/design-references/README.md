# GRAVITYMIND design references

These images record the visual direction explored before implementation. They are reference plates,
not production assets or exact screenshots.

- `home.png`: product-first hero, restrained graphite palette, and procedural apple focus.
- `practice.png`: isolated question workspace and focused feedback hierarchy.
- `flashcards.png`: single-card study flow with deferred statistics.
- `plus.png`: two-plan comparison and payment context.
- `tutor.png`: full-height tutor workspace with visible reasoning stages.

The implemented interface follows `DESIGN.md` as the source of truth. Browser captures used for visual
regression are intentionally ignored under `artifacts/`.
